# biovida.shop

Web estática de biovida.shop, el área de VILLVERG SOLUCIONES INTEGRALES SL que vende moringa al por mayor.

- Sin formularios, sin cookies ni analítica. HTML a mano + `assets/css/biovida.css`.
- Fuentes Fraunces y Manrope servidas desde el propio sitio (licencia OFL en `assets/fonts`).
- Solo datos confirmados por Jose (2-nov-2026): «venta de moringa al por mayor». No añadir origen, formatos, precios ni propiedades de salud sin que él los dé (y las de salud, solo las autorizadas por el Reglamento (CE) 1924/2006).
- Publicación prevista: GitHub Pages con dominio `biovida.shop` (fichero `CNAME`); el DNS está en IONOS.
